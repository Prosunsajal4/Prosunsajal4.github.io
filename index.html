About Me

I am Prosun Mukherjee, an undergraduate student of Electronics and Communication Engineering at Khulna University. I am passionate about software development, artificial intelligence, web technologies, and open-source contribution. I have developed multiple projects using HTML, CSS, JavaScript, React.js, Next.js, Node.js, Express.js, Python, Java, and C/C++. Recently, I have been working on modern web applications including attendance tracking systems, AI-powered prediction systems, Chrome extensions, and productivity tools. I developed a Chrome extension named OnTrack which tracks website activity in real-time with dark/light mode, export functionality, and background tracking support. I also built an AI-based Smart Attendance Predictor using Next.js and Node.js. Besides web development, I have experience with Arduino projects, object detection, crack detection, Android app development, Linux environments, ethical hacking basics, and command-line tools like CMD and PowerShell. Currently, I am focusing on MERN stack development, AI research, and building impactful software products for students and developers.
